# Robotic Arm 7E: Golf Ball Teeing Robot

UWE Bristol, UFMFV8-15-3 Group Design and Integration Project, 2026-27.
A Lynxmotion AL5D arm that picks golf balls and places them on a tee, with an AI assistant for decision support.

## Folders
| Folder | What goes in it |
|---|---|
| `team/` | Members, roles, integration lead |
| `plans/` | Gantt chart, WBS, risk register, requirements, V&V plans |
| `logs/` | Meeting minutes, design notes, test logs |
| `reference/` | Datasheets, articles, application notes |
| `design/` | SysML diagrams and CAD |
| `software/` | MATLAB models and STM32 firmware |
| `docs/` | Evidence write-ups for the report |

## Rules for the team
1. **Don't rename files to make new versions** (no `_final_v2`). Upload the new file with the same name; GitHub keeps every old version.
2. **Every upload needs a clear message** saying what changed, e.g. "Update forearm length to 184 mm measured on real arm".
3. **Name logs by date** (`2026-11-03_...`) so they sort in order.
4. **CAD:** upload the STEP export as well as the SolidWorks file.
